# Hawk Eye downloads

Downloadable Android test builds for Hawk Eye. Application source and private weather credentials are maintained separately.

[Download Hawk Eye 0.2.1 for Android](https://github.com/SolarArk/hawkeye-downloads/releases/download/v0.2.1-test/Hawk-Eye.apk). No GitHub sign-in is required.

Use this repository's **Releases** page to obtain `Hawk-Eye.apk`, `INSTALL.md` and `SHA256SUMS.txt`. Follow [installation instructions](INSTALL.md) to install or update the app. Weather connects automatically with an internet connection; no weather key or activation step is required. Server credentials stay on the server.

Hawk Eye displays fixed terrain and reconstructed weather with Yard, autonomous Hawk Eye and landscape Theatre views. This release supports one configured test location; it does not construct scenery for arbitrary addresses.

See [release notes](RELEASE_NOTES.md) for the build's features, checks and limitations. This is a development-signed testing release, not a Play Store release.
